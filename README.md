## About this mod

Cumulus 9minecraft Mod adds background tools that help other mods change the Minecraft title screen. It gives mods the parts to build new buttons, custom backgrounds, and moving panoramas for the main menu. Players can even pick which menu screen they want to see from the game options. This mod does not add blocks, items, or creatures to your world. It runs quietly in the background and is only needed when another mod, like the Aether series, asks for it to work.
